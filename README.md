# Патофизиология • Тесты (Фролов)

Flutter-приложение для подготовки к коллоквиумам по патофизиологии.

## Возможности
- Разделение на коллоквиумы (I, II, IV)
- 20 случайных вопросов в каждой попытке
- Неограниченное количество попыток
- Сохранение истории всех попыток
- Подробный разбор ошибок с объяснениями

## Запуск
```bash
flutter pub get
flutter run
```

## Сборка APK
```bash
flutter build apk --release
```

APK будет в: `build/app/outputs/flutter-apk/app-release.apk`
